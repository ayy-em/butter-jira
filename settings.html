What token do I need?
A fine-grained token owned by the organisation, with repository access set to only the repos listed under GitHub settings, and these read-only permissions:
PermissionNeeded for
Repository → MetadataMandatory; implied by any other repo permission
Repository → Pull requestsOpen PRs, review state, merged PRs
Repository → ContentsLines pushed straight to the default branch — optional
Repository → IssuesOpen issues assigned to someone
Repository → ChecksThe "checks failing" state — optional
Organisation → MembersThe "Match logins from GitHub org" button — optional
Org owners may have to approve the token before it works; until they do, private repos answer 404 rather than 403. A classic token needs repo + read:org, but repo also grants write access to every private repo you can see — prefer fine-grained.

Org settings Branding shown across the app
Files under assets/brand/ are untracked by git. Drop a logo there and point this at it; single-colour wordmarks are inverted automatically in light theme.
Team settings Who counts as the team
Drives the Team Only filter, display-name overrides, standup, and pull-request attribution. Stored on this device only — it holds colleagues' details, so it never goes into synced storage or a config export unless you tick the box under Backup & transfer.
Each row: display-name override, an optional picture path, an optional Slack display name — standup uses that to build a copy-pastable parking-lot message at the end; type it exactly as Slack's @-autocomplete shows it, spaces are fine — and an optional GitHub login, which is what attributes pull requests to a person when GitHub sync is on. Drop image files into assets/avatars/ in the extension folder and point a row at one (e.g. assets/avatars/sam.png) to replace that person's Jira profile picture everywhere in the app. The path is relative to the extension folder — URLs are not accepted. That folder is git-ignored, since photos of colleagues are personal data. Reload the extension after adding files.
Search needs the "Browse users" permission in Jira. If your account doesn't have it, add people by account ID (from the Jira profile URL) or by email — an email is linked automatically the next time that person shows up in a harvest.
Jira boards and fields Scope, columns, field mapping, hygiene checks
Boards in scope
Status column grouping (Kanban)
Field mapping
Custom field IDs differ per Jira site. Discover resolves them by field name; override manually if your site uses different names. Epic name is optional — company-managed projects give an epic a short label of its own, and team-managed ones fall back to the epic's summary.
Additional fields
Extra field IDs requested on every issue query, comma-separated (e.g. customfield_10050, timetracking). Entries from config.local.json are merged in and shown below.
Monitoring checks
Hygiene checks shown on the Monitor tab. All are on by default; untick to mute one. Every check skips epics and anything already done, and all but "unassigned" also skip sub-tasks — a sub-task hangs off a story, so it has no epic of its own and inherits its parent's dates and estimate.
GitHub settings Repos in scope
One repo per line — nothing is fetched from a repo that is not listed here. A bare name is read as belonging to the organisation set under Personal settings; owner/name and a pasted repo URL both work too. This is the whole scope of the GitHub queries: a token with access to other repos will not pull them in, and an empty list means GitHub sync is off however the enable box is set.
Backup & transfer Move a working setup to another browser
Export writes a JSON file with your site, boards, status groups, field mapping, branding and the GitHub host, org and repo list. Import merges a file back in. The file is browser-neutral — an export from Chrome imports into Firefox or Edge and vice versa.
Neither token is included unless you tick its box below. Both are plaintext in the file: treat an export containing one the way you would treat the token itself, and delete it once the other browser has it.
